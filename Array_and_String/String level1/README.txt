Java String Level 1 Lab Practice - Solutions

Each program is a separate Java source file and contains no comments.

Programs:
1. Compare two strings using charAt() and equals()
2. Create substring using charAt() and compare with substring()
3. Return characters using a user-defined method and compare with toCharArray()
4. Demonstrate NullPointerException
5. Demonstrate StringIndexOutOfBoundsException
6. Demonstrate IllegalArgumentException
7. Demonstrate NumberFormatException
8. Demonstrate ArrayIndexOutOfBoundsException
9. Convert complete text to uppercase and compare with toUpperCase()
10. Convert complete text to lowercase and compare with toLowerCase()

Compile/run any file with:
javac FileName.java
java ClassName
